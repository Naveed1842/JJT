# Manual Workflows (Phase-1)

All workflows are human-controlled. No automated sponsor sourcing or payments.

## Child registration
- Capture child identity and required profile data
- Create child record
- Create the child's ledger
- Set monthly education cost

## Monthly ledger entry
- Confirm education cost for the month
- Record a new ledger entry (append-only)
- Ensure only one entry per child per month
- Record whether coverage is Early Support Pool or sponsorship
- If sponsorship, reference the sponsorship commitment

## Monthly progress update
- Collect the update for the same month as the ledger entry
- Record the progress update
- Verify it aligns with the ledger month

## Sponsorship commitment (future-only)
- Record sponsor and sponsorship commitment
- Set start month in the future
- No payments are collected in Phase-1

## Status review
- Support status is derived from the ledger
- Staff review derived status for accuracy and follow-up

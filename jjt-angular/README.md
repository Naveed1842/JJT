# JJT Angular Frontend

Angular frontend for the JJT Platform (Early Education Support Platform).

## Backend
The Spring Boot backend runs on http://localhost:8080

## Setup

```bash
npm install
```

## Development Server

```bash
npm start
```

Navigate to `http://localhost:4200`

## Build

```bash
npm run build
```

## Project Structure

- `/src/app/pages/home` - Landing page
- `/src/app/pages/children` - Children list
- `/src/app/pages/child-detail` - Child detail page
- `/src/app/pages/admin` - Admin dashboard
- `/src/app/pages/sponsor` - Sponsor portal
- `/src/app/services` - API services
